# 学情可视化展板

静态 HTML 应用。个人分析、小题分析、趋势、班级对比、智能分析和综合诊断沿用原来的分析规则；座位模块的统计与互补口径见下文。

## 数据入口

在“上传管理”中，通过三个并列区域的“选择总表文件”“选择小题表文件”“选择PDF/MD试卷”导入对应文件。页面恢复原来的独立卡片、分类颜色与按钮，三个入口共用新版导入队列、解析、匹配和保存流程。总表与小题表支持 `.xlsx`、`.xls`、`.csv`，可以一次选择多个文件；同名同类型文件在解析成功后替换原文件，解析失败保留当前数据。

总成绩表模板可在同一位置下载。表头支持 1–3 行及 Excel 横向合并单元格；姓名、班级、分数、等级和题号保持原来的识别方式。每个文件单独检测表头，多文件解析完成后统一合并。小题满分沿用文件表头，不从最高得分推算。

数字与等级使用统一格式：全角数字转为数字，保留零分，空白和占位符不作为有效单科成绩；等级统一大小写。班级 `801`、`01班`、`一班` 等按同一班级匹配，显示为 `01班`；学生按“姓名 + 班级”匹配，跨班重名保留为不同学生。主成绩表的单科分数、等级和排名优先于小题表附带的同类字段。

保存后自动进入“新建批次”。批次包含原始表格、合并表头、小题元数据与原始 PDF 字节，刷新后仍可重新调整表头或解析 PDF。旧 JSON/base64 批次仍能读取；旧版本未保存的原始表格无法凭空恢复，但不会因为重新调整表头而清空已解析的成绩。

## 共用模块

- `app-core.js`：输入规范、学生身份、PDF 字节、顺序存储队列、工作簿读取、图表创建/释放和节流缩放。
- `spreadsheet-worker.js`：在后台线程读取 Excel / CSV；直接打开本地 HTML 或 Worker 不可用时回退到相同格式的主线程解析。
- `app.css`：集中维护颜色、控件、字号层级与字体。正文基准 14px，页面/控件/图表使用同一中文字体栈；数学公式保留数学字体。Word 普通文字统一为微软雅黑。
- `reports.js`：个人、班级、单科、进退步、临界预警、学科关联和座位图文报告，共用报告图表规范。
- `class-comparison.js`：班级均分、热力图、等级/名次分布、箱线图及相关导出。
- `seating.js`：座位数据模型、布局交互、快照与事件绑定。
- `seating-data.js`：所选考试的年级/班内成绩统计、互补判断、学生变动匹配、排位校验和持久化快照。
- `index.html`：页面、数据导入、小题分析、趋势与综合诊断等剩余业务。业务模块在页面 DOM 就绪后、主脚本执行前按顺序加载，下载通过 preload 并行进行；沿用经典脚本，兼容直接打开 HTML。

模块拆分时将 `index.html` 从 17,849 行、1,010,749 字节调整为 11,835 行、649,960 字节。主要通过按业务拆分实现，并清理 29 处图表创建前的重复释放。业务模块没有删除或压缩成难以维护的代码；此处行数减少不等于项目总代码减少同样数量。

成绩表单文件上限 50 MB，后台解析超时为 60 秒；错误会显示在导入状态中。保存失败不会把页面切换到空白新批次，删除失败会恢复原批次列表。导入、恢复和保存期间禁用会改变当前批次的控件，程序切换批次后的旧导入结果也不会写回新批次。

## 座位保存与恢复

每个班级独立保存排位、学生标签、固定/关注状态、禁用空位、标签显示和已应用的高级设置。同一班级切换考试或刷新成绩时，保留人工排座，更新本次成绩统计；新加入的学生填入空位，离开的学生释放座位，原来主动移到待分配的学生继续保留在待分配区。

点击座位图的“新增位置”，在上方、下方或已扩展行的“＋”处新增一个空座，也可点击“上方增加整排”或“下方增加整排”，完成后点击“完成”。布局保留八列和原有过道；单个新增位置不自动生成其余七个座位。每个实际座位都有独立编号，前方新增位置时原有学生和固定座位仍对应原编号。空座可拖入待分配学生，新增空座不会被智能排座自动填满。快照、刷新恢复和复原 JSON 同时保存座位形状与编号，轮换、分组和空余统计跳过没有座位的位置。

每次有效改动都自动追加快照，包括手动拖动、标签/状态调整、轮换、智能排座、设置应用和清空排位。历史不再限制为最近十份，也不会因刷新或关闭浏览器删除。列表先显示最近 50 份，可展开更早记录；每份记录注明时间、改动原因和考试批次。恢复或导入排位前保存当前状态，恢复后再追加一份快照，因此不会覆盖后续历史。

改动先同步写入本地待保存记录，再按顺序写入 IndexedDB；浏览器在异步写入完成前关闭，重新打开时重放尚未完成的记录。保存失败会显示真实状态。不同项目的座位档案按页面路径隔离，旧版可确定所属班级的快照自动迁移。保存属于当前浏览器和站点；换设备或清除站点数据前可使用“导出复原JSON”，之后通过“导入复原JSON”恢复。Excel 用于查看排位和统计，JSON 用于恢复设置。清空排位保留学生与所有历史。

## 座位成绩与学科互补口径

在座位页选择“本次考试”和“对照考试”，最多两次，不会自动选择最近保存的批次。同一考试只计一次；选择后立即计算总分、单科与全部学生对的互补缓存。考试选择、年级有效人数、分组大小和计算时长随班级设置保存。默认“当前成绩”跟随主批次；选择具体考试后保持该选择。学生名单以当前班级为准，历史成绩不恢复已经离班的学生。

年级位置为 `有效年级名次 / 该考试该科年级有效人数 × 100%`，数值越小越靠前。总分和每科分别计算，两次有效位置等权平均；只有一次有效记录则使用该次并标记，缺失不补零。零分有效，缺考不作为薄弱，缺失总分不由单科拼成总分。有效人数可以按考试统一填写，也可以按单科填写；`名次/人数` 格式可直接提供分母。名次超过人数或未知分母时，不生成该项年级位置。

学生详情按“科目—平均位置”显示，总分和每科各一个平均位置。所选考试中存在有效英语总成绩时，将“英语”“英语合”“英语合并”“英语总分”统一为一个“英语”，听说、笔试不再重复参与统计与互补判断；没有英语总成绩的考试不以分项替代总成绩。该整理只用于座位统计，不改写导入的原始成绩。

只有导入多班并在高级排位勾选“已覆盖全年级”，才可依据完整导入的有效成绩或名次计算年级人数。导入部分学生但有年级名次时，需要提供真实年级有效人数；只填人数不能将本班得分虚拟扩充为全年级。自动模式发现任一所选考试年级依据不足时，两次都统一采用明确标注的“班内预实验位置”；手动选择年级成绩时，依据不足的项目保持缺失。

并列名次采用竞争排名，如 1、2、2、4。总分与单科均按平均位置每 12.5 个百分点分为 L1–L8，同分不拆层。单科层差至少 1 且位置差至少 10 个百分点时，较靠前的一方可帮助另一方。双向互补要求双方各至少一科帮助对方；紧迫性按层差 1、2、3 分，3 层以上封顶为 3，不累加单向大差距来冒充双向互补。

同桌总分层差不超过 2、关系不和不可同桌；固定位置、禁用位置、原空位和待分配名单均由搜索保留。缺失总分的学生不能自动组成成绩互补同桌，可保留在已有单人座位。总分位置差 **>10 且 ≤25 个百分点**为适中，只统计符合条件的双向互补同桌。辐射学生为班内总分平均位置前 20%（含临界同分）；本组至少有一名即计覆盖，本组没有时才统计上下左右邻组补充，多名学生不重复加覆盖。分组采用偶数人数，不拆同桌、不跨过道。

学业模式与综合模式按以下顺序逐项比较方案：双向互补同桌数 → 本组高分覆盖 → 相邻组补充 → 适中互补 → 双向科目均衡 → 双向紧迫性 → 单向补充 → 行为偏好。后面的奖励不会抵消前面的损失，硬约束不参与奖励抵消。行为模式优先行为偏好，小组模式优先小组覆盖，但仍服从同样硬约束。

`seating-engine.js` 将每对学生的帮助方向、双向互补、总分差距和限制缓存为查表数据；50 人为 1,225 对，排位变化直接复用。`seating-search-worker.js` 在后台执行多起点、交换、扰动和最佳方案保留；默认计算 5 秒，可选择 10 或 20 秒，取消了连续 15 轮未改善即停止的规则。后台线程不可用时分片回退，手动修改、切班或成绩变化会取消旧搜索，避免覆盖新操作。显示实际有效评分次数，次数随设备和数据变化；结果为该次搜索找到的最佳方案，不代表已证明全局最优。

页面详情、统计、帮助网络、图文/Markdown 报告和 Excel 统一复用该数据与判断。恢复旧排位保留当前考试选择并重新计算成绩；复原 JSON 同时恢复其考试设置。快照保存机制见上一节。

## 验证

应用运行不需要安装 npm 依赖。开发回归测试可执行：

```sh
npm install
npm test
npx playwright install chromium
npm run test:browser
```

已有 Chromium 时可设置 `CHROMIUM_EXECUTABLE`；浏览器启动参数可用 `CHROMIUM_ARGS` 提供 JSON 数组。

测试覆盖输入格式、班级与重名身份、PDF 多种旧格式、后台/回退解析、多文件一次合并、失败与重复导入、保存/刷新恢复、原始表头保留、8 个功能页、热力图三种视图与 PNG 导出、进退步模型、存储写入顺序和旧批次迁移。上传页面另外验证三个按钮的文件选择、导入期间按钮禁用，以及桌面并列/窄屏堆叠布局。本轮补测模块下载延迟、7 类图文报告实际生成、座位交互与快照，以及打印前后事件。

座位专项测试另覆盖用户选择两次考试、独立年级分母、全年级覆盖确认、八层边界、缓存复用、严格目标优先级和 40,320 种小样本排列的穷举参考。原有测试覆盖同分、零分/缺考、原始排名回退、跨班重名、总分缺失、新生/离班与待分配保留、20 次以上快照、跨班/跨考试恢复、固定/禁用位置轮换、实际优化器、Excel/报告统计一致、JSON 导出导入、数据库写入失败，以及关闭整个浏览器后恢复连续未完成写入。

新增布局测试覆盖单座/整排添加、补齐同一行、固定座位编号、真实拖放、非座位留白、刷新、轮换、后台排座、形状快照与 JSON 恢复，并验证平均位置表格及英语合并不会改写原始成绩。

本次本地 Chromium 基准：同一组 5000 名学生（无班级的唯一姓名，单科与一小题）连续合并三次，原版耗时 1244 / 1392 / 1470 ms，优化后 68 / 55 / 44 ms。该结果包含学生合并、搜索索引、名单和备用排名，主要反映消除逐行扫描姓名表的收益，不代表所有页面或数据规模的固定性能提升。
